# Two-permutation cross-over specificity

Registered 2026-09-28 before calculation. Retrospective analysis of the existing released SurfPro checkpoint outputs, not a prespecified original experiment or new replication. Existing arm means for intended counterfactuals were known. The new wrong-target contrasts below have not been calculated in this remediation.

Use all 887 entries from retained N, Cpi and Cpi2, with the original official globalxx per-sequence scorer. First verify all arrays have the same denominator, valid range, and their means agree with saved summaries. Inspect scoring provenance and raw target sequence order if retained. If cross-arm order cannot be independently reverified, state that limitation and use a within-arm intended-minus-other statistic (which has verified pairing in score_arms.py) as the primary contrast.

Primary statistic: S = 0.5 * [(score(Cpi,pi)-score(Cpi,pi2)) + (score(Cpi2,pi2)-score(Cpi2,pi))]. Positive S means each intervention preferentially follows its own target; a target being generically easier cannot explain both directions. Report both within-arm contrasts and each target's native-arm agreement. Subtract native-arm target asymmetry in the secondary difference-in-differences D1, D2. Report S with a paired chain bootstrap only if order is verified; otherwise use independent within-arm chain resampling for a conservative alternative and mark pairing assumption. 10,000 resamples, RNG 271. Report chain-level positive fractions, quantiles, and mean/median as sensitivity. Do not select permutations, subsets or scorer after looking at contrasts. Intervals quantify chain sampling conditional on fixed checkpoint and these two chosen permutations; no permutation-population or causal universality claim. Budget: local CPU <10 minutes, $0.

Pre-execution clarification: the retained per-chain score arrays have no chain IDs, and raw Cpi/Cpi2 reference files were not found in the project inventory. Therefore the primary interval for S will average the endpoints of two within-arm 97.5% percentile intervals (Bonferroni bound for the two constituents, nominal at least 95%, subject to bootstrap approximation). This avoids assuming cross-arm ordering or independence. Paired S/D1/D2 and cross-arm per-chain summaries will be labeled conditional on the original common ordering, not independently verified. No independent-bootstrap interval will be called conservative without a covariance assumption.
